# Code of conduct

## The short version

Be decent. Argue about the work, not the person.

## What that means here

**Good**: disagreeing hard about a design, saying "this is wrong and here's why",
asking a question that seems obvious, admitting you broke something.

**Not good**: personal attacks, dismissing someone for not knowing something yet,
making the project unpleasant to be near.

Technical disagreement is welcome and expected — this tool exists because someone
disagreed with how documentation usually works. Contempt is not disagreement.

## If something goes wrong

Email **conduct@everywan.com**. It goes to the maintainers. We'll take it
seriously, keep it as private as we can, and tell you what we did.

Maintainers who don't follow this are held to it harder than anyone else, not
less.
